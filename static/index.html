SimpleFIN connection

To pull real data: create an account at SimpleFIN Bridge (beta-bridge.simplefin.org), connect your banks and brokerages there, then generate a setup token and paste it below. The token is exchanged once for an access URL that is stored only in the local database on this Mac (data/audit.db) — it is never displayed again or sent anywhere else.

Import a statement file (CSV / OFX / QFX)

For institutions SimpleFIN can't reach (e.g. Amex right now): download activity from the institution's website — QFX/OFX preferred, CSV works too — and import it here. Re-importing the same file skips duplicates, and card payments are automatically matched against your checking account as transfers.
